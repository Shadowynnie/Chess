# Chess

This is a simple chess game implementation in C++.

## Features
- Graphical user interface using SFML
- Basic chess rules implementation
- Multiplayer support using ENet (to be added)
- Singleplayer mode against a basic AI (to be added)

## Requirements
- C++17 or higher
- SFML library
- ENet library (for multiplayer support)
- CMake (for building the project)

## Building the Project
1. Clone the repository:
   ```bash
   git clone
2. Navigate to the project directory:
   ```bash
   cd chess
   ```
3. Create a build directory and navigate into it:
   ```bash
   mkdir build && cd build
   ```
4. Run CMake to configure the project:
   ```bash
   cmake ..
   ```
5. Build the project:
   ```bash
   make
   ```
6. Run the executable:
   ```bash
   ./chess
   ```
7. Enjoy playing chess!
