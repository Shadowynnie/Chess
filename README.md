# Chess

This is a simple chess game implementation in C++.

## Features
- Graphical user interface using SFML
- Basic chess rules implementation
- Multiplayer support using ENet (to be added)
- Singleplayer mode against a basic AI (to be added)

## Requirements
- C++17 or higher
- SFML library
- ENet library (for multiplayer support)
- CMake (for building the project)
